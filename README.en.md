# Java Exercises — Gustavo Ben Abraham

[Português](README.md) | **English**

A collection of Java exercises and practice programs organized by lessons and developed while studying with Eclipse IDE.

## Topics and structure

The `CursoJavaBasico/src/` folder contains lesson packages covering early Java programs, variables and data types, keyboard input, operators, conditionals and switch statements. The collection grows as my studies progress.

Technologies: Java, Eclipse IDE, Git and GitHub.

## Get started

```bash
git clone https://github.com/GustavoBenAbraham/java-exercicios.git
```

Open the course project in Eclipse, inspect the exercise package you want and run its Java entry point. Exercises are separate programs; this repository is not one web application.

## Git automation script

The course folder contains a Windows batch script that automates staging, committing, pulling and pushing. Inspect the script and configure its repository path before running it.

The underlying sequence is:

```text
git add .
git commit -m "your message"
git pull origin main
git push origin main
```

Pulling before pushing synchronizes changes but does not guarantee a conflict-free merge. Resolve any conflicts before pushing.

Programming logic, Java syntax, console input/output, branching, package organization and the Git workflow.
